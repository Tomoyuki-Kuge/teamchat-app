### HTTPメソッド上書きの修正（2026-11-10）

静的レビューで、POSTを`_method`や`X-HTTP-Method-Override`でGET・HEADに上書きすると、公開APIの405判定を通過することを指摘。設計の実装方針を先に補足し、`PublicApiMethods`でAPIリクエストの上書き元を取り除いて実際のHTTPメソッドへ揃えた。これによりHEADへ偽装されたPOSTも、所定のエラーJSON本文を返す。通常画面のフォームのメソッド上書きは維持する。

- 修正前：本文・クエリ・ヘッダーからGET／HEADへ上書きする6ケースが、期待405に対して200となる失敗を確認（終了1）。
