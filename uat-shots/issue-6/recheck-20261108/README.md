## 強調処理と入力の追加確認

- **正規化後に重複する語**：`abc ＡＢＣ ガ ｶﾞ 会社 가`でID71・57の2件。各行で原文の`ＡＢＣ`・`ｶﾞ`・`㍿`・`ㄱㅏ`がそれぞれ一度ずつmarkとなり、検索欄は入力語の表記を保持した。[Unicodeと重複語](08_unicode-duplicates.png)
- **メモリ不具合の再現入力**：確認用本文ID73は`a`×1,000文字。検索語`a `×600回（1,200文字）をフォームから送信しHTTP 200で結果を表示した。検索欄は末尾空白を含めて入力を保持し、ID73の本文は1つのmark（1,000文字）となった。サーバーのピークメモリは画面UATでは測定していない。[600回の重複語](09_repeated-600-words.png)
- **空白だけの検索**：HTTP 422で「検索キーワードを入力してください」。入力欄は`required=false`、`checkValidity()=true`、`validationMessage=""`であり、ブラウザー標準検証ではなくサーバーで拒否している。[空入力](10_empty-input.png)
- 長い検索語は結果見出しで折り返され、並べ替えの「投稿日時」も縦に折り返された。検索・結果表示は利用できたが、長文入力時の表示上の制約として記録する。
